## Access and availability
BLS public JSON, FRED graph CSV, BEA published workbook, EIA published history/PDF, IMF DataMapper and World Bank workbook are keyless official publication routes. BLS registered API access, BEA NIPA API, FRED API and EIA API require free keys for their keyed routes; this implementation uses inspected published downloads, so no keys are added to browser code or configuration. BEA NIPA T10101 is the official percent-change table but its API is not used here.

The EIA global-oil HTML endpoint returned an official Unexpected Error page despite HTTP 200; it is not treated as data. The alternate official Table 3e PDF is validated separately. IMF legacy WEO database page returned 404; DataMapper provides explicit WEO edition metadata and world values. Any failed/changed publication leaves its card unavailable, or retains a previously verified observation with cycle-based freshness. Full live refresh results are recorded separately after tests pass.

## Storage and freshness
Existing macro_indicators stores all required fields and key + period + source uniqueness; no migration is needed. Geography and expected cycle are metadata derived from canonical keys. Nigerian provider modules remain unchanged. Monthly 75-day, quarterly 180-day, weekly 21-day, daily 10-day and WEO 220-day release windows allow publication lags. Annual forecasts use official edition publication metadata rather than treating the reference year as an observed date; current-year selection never promotes 2031 over 2026. Retrieval does not reset publication age.
